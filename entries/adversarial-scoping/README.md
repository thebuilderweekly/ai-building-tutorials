# Kill a bad product idea before you spend a week building it

An agent runs six adversarial critique passes in two minutes and surfaces objections a solo founder never asks themselves, where a human review panel takes three days to assemble and half the panel will be polite.

## What this tutorial teaches

**Before:** You have a PRD you're excited about. You start building. Four days in you realize it solves the wrong problem.

**After:** Before you write any code, an agent runs six adversarial critiques against the PRD and surfaces the three objections that would have killed the idea on day four.
